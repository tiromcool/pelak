# ابزار مدیریت پلاک رانندگان

اپلیکیشن فارسی و راست‌چین برای مدیریت مشتریان، رانندگان و پلاک خودروها. اطلاعات عملیاتی فقط در IndexedDB همان مرورگر/دستگاه ذخیره می‌شوند و به سرور یا API خارجی ارسال نمی‌شوند.

## امکانات
- نمایش کارت مشتریان و رانندگان، جستجوی زنده در نام مشتری/راننده/پلاک و مرتب‌سازی
- نرمال‌سازی «ی/ي» و «ک/ك» برای جستجو
- کپی دقیق رشته پلاک بدون تغییر رقم، حرف یا فاصله؛ با کلیک روی خود پلاک یا دکمه کپی
- ثبت سریع مشتری و راننده با دکمه پاک کردن فرم؛ استفاده مجدد از مشتری موجود و جلوگیری از ثبت تکراری راننده/پلاک برای همان مشتری
- داشبورد مدیریت برای افزودن، ویرایش و حذف مشتری/راننده با تأیید حذف
- پشتیبان JSON، اعتبارسنجی فایل، بازیابی با انتخاب ادغام یا جایگزینی، خروجی CSV
- حالت جمع‌وجور، تنظیم نمایش کارت‌ها و تنظیم ذخیره‌شونده عرض چیدمان؛ میانبرهای Ctrl+F، Ctrl+N و Escape
- PWA با manifest، آیکون‌های محلی و Service Worker برای App Shell آفلاین

## اجرای محلی در Windows
Service Worker و نصب PWA روی `file://` فعال نمی‌شوند. Python 3 را نصب کنید، در پوشه پروژه CMD/PowerShell باز کنید و اجرا کنید:
```powershell
py -m http.server 8000
```
سپس در Chrome یا Edge آدرس `http://localhost:8000` را باز کنید و از آیکون نصب مرورگر یا منوی آن برنامه را نصب کنید. برای میزبانی شبکه‌ای/عمومی HTTPS لازم است.

## آفلاین
پس از اولین بار باز کردن موفق برنامه در localhost/HTTPS و تکمیل Cache، فایل‌های اصلی برنامه از Service Worker ارائه می‌شوند. دیتابیس IndexedDB مستقل از Cache است و با به‌روزرسانی Cache پاک نمی‌شود. قطع اینترنت را از DevTools یا تنظیمات شبکه آزمایش کنید.

## پشتیبان‌گیری
از داشبورد مدیریت > پشتیبان‌گیری و بازیابی، JSON کامل بگیرید. فایل را انتخاب کنید تا تعداد مشتریان و رانندگان اعتبارسنجی شود؛ سپس ادغام یا جایگزینی را آگاهانه انتخاب کنید. خروجی CSV شامل نام مشتری، نام راننده و پلاک است.

## حریم خصوصی و محدودیت‌ها
- داده‌ها فقط در پروفایل مرورگر و دستگاه فعلی هستند. پاک‌کردن داده‌های سایت/مرورگر ممکن است آن‌ها را حذف کند؛ مرتب پشتیبان بگیرید.
- Clipboard API در محیط امن (HTTPS یا localhost) بهترین عملکرد را دارد.
- PWA مرورگر معمولی کنترل قابل اتکایی برای Always on Top ندارد.
- PWA به‌تنهایی فایل EXE تولید نمی‌کند.
- تست نصب واقعی روی Windows و قطع کامل اینترنت روی دستگاه کاربر از این محیط قابل انجام نیست؛ آن تست‌ها باید روی سیستم مقصد انجام شوند.

## آزمون پذیرش پیشنهادی
1. با localhost اجرا و یک مشتری و دو راننده با پلاک فارسی ثبت کنید.
2. برنامه را Refresh و سپس ببندید و دوباره باز کنید؛ داده‌ها باید باقی باشند.
3. جستجوی نام مشتری، راننده، پلاک و گونه‌های «ی/ي» و «ک/ك» را بررسی کنید.
4. پلاک را کپی و در Notepad بچسبانید؛ باید دقیقاً همان رشته ثبت‌شده باشد.
5. ویرایش/حذف از داشبورد و حذف مشتری همراه رانندگانش را بررسی کنید.
6. JSON خروجی بگیرید، یک داده آزمایشی اضافه کنید و بازیابی ادغام/جایگزینی را بررسی کنید.
7. پس از Cache شدن، اینترنت را قطع و عملیات اصلی را دوباره امتحان کنید.
